# Academic website — Manuel Méndez Hurtado

A responsive, static academic website built with HTML, CSS and a small amount of JavaScript. It is designed to be hosted for free with GitHub Pages.

## Files
- `index.html` — all page content and sections
- `styles.css` — layout, typography, colours and responsive design
- `script.js` — mobile navigation and automatic footer year

## Before publishing: personalise these items
1. Replace `REPLACE_WITH_YOUR_UCM_EMAIL` in `index.html` with your institutional email address.
2. Replace the generic Google Scholar, ORCID, DBLP and GitHub links with your actual profile URLs.
3. Check the selected publications: complete author lists, venue, year and DOI/publisher links. Remove any entry that is not ready to publish.
4. Add official URLs and concise descriptions for research projects.
5. Optional: replace the initials avatar (`MMH`) with a professional photograph. Put the image in this folder (for example `assets/profile.jpg`) and update the profile area in `index.html`.
6. Review all wording and claims before making the site public.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **new public repository** named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root. You can use **Add file → Upload files** in the GitHub website.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes and visit `https://YOUR-GITHUB-USERNAME.github.io/`.
7. Each time you edit and commit the files, GitHub Pages rebuilds the site automatically.

## Important
- This is a static site: it needs no server, database or build tools.
- Do not upload private documents, student data, confidential project information or papers you are not permitted to distribute.
- The Google Fonts import requires an internet connection; the site will fall back to system sans-serif fonts if unavailable.
